# Clip N Copy Showcase

Create a premium, modern, fully responsive STATIC E-COMMERCE WEBSITE for a stationery store called Clip N Copy.

This is a frontend-only static website. Do NOT create a backend, database, authentication, Supabase integration, payment gateway, real order processing, or server-side functionality.

The goal is to create a highly polished e-commerce UI prototype that looks and feels like a real online stationery shopping website.
